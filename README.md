# BuildMate

Рабочее название. Десктопное приложение для League of Legends: статистика, личная аналитика,
рекомендации предметов по составу врагов, изменения патча для твоего пула чемпионов.
 Не влияет на игру и не показывает скрытую информацию.
Влияет на собственный анализ, анализ чемпионов, предметов, меты.
Этапы: docs/stages.md. Прогресс: docs/progress.md.
