# Источники данных и правила

## Riot API
- Личный ключ из .env, лимиты соблюдать: очередь запросов и ретраи на 429.
- Перед публикацией проекта перечитать политики Riot для сторонних приложений.

## Data Dragon / Community Dragon
- Статика (чемпионы, предметы, руны, иконки, патч). Кэш по патчу.

## LCU и Live Client Data
- Только чтение. Ничего не отправляем в клиент и игру, никаких автоматических действий.
- Показываем только то, что обычный игрок видит на своём экране.

## Lolalytics (опционально, этап M5)
- Честный User-Agent: BuildMate/0.1 (личный проект).
- Один запрос за раз, пауза 1-2 секунды, соблюдать robots.txt, только данные для нашего пула чемпионов.
- Кэш по патчу, обновление по кнопке или при выходе нового патча.
- При 403, 429 или капче защиту не обходим: провайдер отключается, переключаемся на собственную выборку из Riot API, в UI пометка «источник недоступен».
- Данные Lolalytics не коммитим в репозиторий и не используем для обучения ИИ или передачи в LLM.

## League of Graphs
- Не используем: их правила запрещают парсинг.
