# Что мы делаем (BuildMate)

Десктопное приложение для игроков League of Legends. Проект для себя и GitHub, не для монетизации.
Рабочее название BuildMate. Приложение ничего не меняет в игре и не показывает скрытую информацию:
только статистика и решения на её основе.

## Зачем
Сайты вроде Lolalytics показывают «средний мир» и не знают конкретного игрока. Хочется инструмент,
который сводит общую статистику, мои собственные матчи и состав врагов в понятную подсказку.

## Главные функции
1. Рекомендации предметов в зависимости от пиков врагов и роли чемпионов (контроль, лечение, AP/AD, танки, бёрст).
   Работает даже без статистики: правила и базовые кор-предметы. Каждая рекомендация с объяснением «почему».
2. Личная статистика по моему аккаунту (Riot API): винрейт, билды, руны по чемпионам и матчапам.
   Малые выборки сглаживаются глобальными данными.
3. Упрощённая общая статистика по примеру Lolalytics (источник заменяемый, кэш по патчу, обновление по кнопке).
4. Список изменений патча для моих чемпионов («Что изменилось у твоих»).
5. Позже: champ select (LCU, только чтение), журнал матчапов, подсказки во время матча (только то, что видно на экране), разбор после игры.

## Принципы
Только публичные данные. Никакой автоматизации в игре и клиенте. Источники заменяемые. Всё кэшируется по патчу.
Приложение работает офлайн на кэше. Правила источников: docs/sources.md. Этапы: docs/stages.md.
